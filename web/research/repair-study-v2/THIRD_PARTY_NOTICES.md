# Third-party source material

This viewer embeds unmodified before-source files from the frozen repair-study
catalog. File identity, source SHA-256 and observed-evidence SHA-256 remain
available in the page and exported task. It does not embed reference fixes.

- Triton 3.8.0 Python source: MIT-style license, reproduced in
  `licenses/TRITON-LICENSE.txt`, copied from the measured before runtime's
  `triton-3.8.0.dist-info/licenses/LICENSE`.
- Liger Kernel source: LinkedIn Corporation BSD 2-Clause license, reproduced in
  `licenses/LIGER-LICENSE.txt`. The same upstream license occurs in the before
  snapshots for the three included Liger cases. Additional upstream component
  notices from those before trees are retained under `licenses/liger/`.

Source files and their original headers are displayed without rewriting. Other
research tools, data preparation and this viewer are repository work. Numeric
observations are measured facts; the UI browser checks are software checks and
do not establish additional GPU performance or human-comprehension outcomes.
