# 系统研发与软件生态

日期：2026-10-16。适用于黄Sir的算力工坊和创业 PvE。

从单颗 GPU 的计算、缓存和显存成长，扩展到整套系统交付与开发者生态。新研发区独立于原硬件商店和应用任务；旧存档继续经营，系统与生态从零开始。

## 可以投资什么

| 投资 | 经营收入门槛 | 首级资金 | 定位与取舍 |
| --- | ---: | ---: | --- |
| PCIe 接入 | $900 | $450 | 通用服务器接入，是互联、网络与机柜的基础；可与 NVLink 同时建设，机柜建成后二、三级每级增加 3% 系统交付效率 |
| CUDA 工具链 | $500 | $300 | 投资软件接入能力，获得客户订单溢价，开启加速库研发 |
| 加速库 | $1,800 | $900 | 把已有计算能力交付给应用客户，提高大型项目交付效率 |
| NVLink 多卡互联 | $4,000 | $2,500 | 机柜与网络建成后改善多卡系统项目交付，单独购买不会提高单卡吞吐 |
| IB 合作采购 | $6,000 | $3,500 | 较低初始投入，通过供应商建设网络，承担较高的持续费用 |
| 收购网络团队 | $12,000 | $10,000 | 较高初始投入，获得较低的持续费用和更大的客户需求；以 Mellanox 收购为灵感 |
| 机柜集成 | $9,000 | $5,000 | 要求 PCIe、加速库、HBM 和一条网络路线，改善整套系统交付并扩大客户需求 |
| 开发者生态 | $3,000 | $1,800 | 在工具链和加速库之上投资应用适配、开发者支持，带来订单溢价与新增需求 |

资金是游戏内货币，门槛是累计经营收入；IPO 不增加研发收入。所有项目另有硬件和系统前置条件，页面展示具体缺项，规则以 `lib/business-game.js` 为准。除网络路线为一次性选择，其他项目最多三级，后续级别成本按首级价格乘 `1.9^已购级数` 向上取整。

合作采购与收购网络团队互斥，表示这场游戏的采购策略选择；现实中收购和合作可以并存。两条路线均允许机柜研发。PCIe 作为基础接入保留，NVLink 是可选的多卡协作投资，不能把 PCIe、NVLink 和 IB 当成同一层级链路。

## 收益如何进入游戏

- **客户溢价：** CUDA 工具链与开发者生态提高普通订单单价；当前两项均升至三级时增加 48%，规则上限为 60%。实际订单按交付时的生态水平结算，奖励保留到分；应用合约的一次性奖励不变。
- **市场需求：** 创业赛的原有需求上限加上开发者、网络和机柜带来的新增需求，新增量最多 $12/秒。需求表示客户总预算，实际收入仍受此上限约束；已经触及预算时，只提高单价不会提高总收入，需要同时拓展需求。有需求也不保证现有硬件能全部承接。
- **系统交付：** 加速库提高大型项目交付效率；机柜与网络支撑多卡系统，NVLink 的系统收益要求已经建成机柜与网络。倍率最多 2.5，应用于创业赛训练和商业首单，以及工坊的训练、长序列推理和 AI 工厂合约。
- **资本与成本：** 研发购买减少现金，不增加营业收入。创业赛把系统投资计入设备账面价值，工具链维护、网络与机柜费用计入持续运营成本；供货合作的费用高于收购路线。公司破产后停止研发。

工坊采用一次性研发投入，不扣这条线的持续费用；创业赛采用完整运营费用与破产规则。工坊的日常接单数量仍由原有队列和硬件决定，新需求指标用于创业赛。对手在原有硬件计划完成或商业化后，根据盈利和现金储备自主建设生态，Lisa 偏向收购路线，灰盒实验室偏向合作采购。

这是一层独立的经营抽象，不改变 `lib/compute-model.js` 的单颗 GPU 周期、带宽、命中率或吞吐。没有模拟实际 PCIe/NVLink/IB 的数据包、拓扑、拥塞、集合通信或机柜散热，研发等级也不对应真实协议代际。所有倍率、价格和成本均为未实测标定的游戏设定。

## 技术史与来源

NVLink 是 NVIDIA 自研的互联技术，2014 年公布；不是收购一家“NVLink 公司”获得的技术。[NVIDIA NVLink 发布公告](https://nvidianews.nvidia.com/news/nvidia-launches-world-s-first-high-speed-gpu-interconnect-helping-pave-the-way-to-exascale-computing)

NVIDIA 于 2020 年 4 月 27 日完成 Mellanox 收购，整合其 InfiniBand 和以太网网络能力。游戏中的收购价格、团队与经营效果是虚构设定，不复现真实交易。[NVIDIA 完成 Mellanox 收购公告](https://nvidianews.nvidia.com/news/nvidia-completes-acquisition-of-mellanox-creating-major-force-driving-next-gen-data-centers)

PCIe 是 PCI-SIG 的行业标准；CUDA Toolkit 包含编译器、运行时、加速库以及调试和优化工具。开发者生态通过应用与工具支持形成价值，不能只用购买 GPU 数量替代。[PCI-SIG 规范目录](https://pcisig.com/specifications)、[CUDA 官方文档](https://docs.nvidia.com/cuda/doc/index.html)
