## 1. 研究问题和对照设计

问题是：在相同源码、可见运行事实和资源上限下，允许查询派生关系，是否改善模型提交的可执行修复及证据获取成本？研究对象是 GPU 编译器和 AI 算子的真实错误，包括轴广播、浮点符号、编译期过滤、低精度归约、数值稳定性及布局步长。这里的“无工具”准确指无专用派生诊断功能，仍有相同的普通列表、搜索、源码读取和原始证据接口。

主终点在候选生成前冻结：原样补丁能应用、实际构建成功、冻结隐藏用例全部通过、候选源码树及完整输出验证收据一致。可见＋隐藏同时全过另外报告为更严格的回归检查。次要定位分数只表示有限行区间命中预定义函数且引用失败/通过观测；它不自动证明解释的语义、因果关系或人类理解。

旧 CUTLASS/TMEM 两个故障是开发材料，未混入本轮六根因统计。本轮的 `holdout` 指未用于此通用查询机制的项目开发/调试，不意味着团队不认识缺陷、任务选择盲法，或公开源码不在模型训练数据中。

合计 **6 个根因、89 个输入用例（25 可见、64 隐藏）、每版本 308,784 个输出**。原实现 41/89 通过；对应官方修复 89/89 通过。输入形状、seed、重复运行和输出元素不计为独立根因。官方修复是可修复性控制，不是 agent 成绩。

本轮设备原样记录为 NVIDIA GeForce RTX 4090 / SM89，driver 610.57.04，PyTorch 2.7.1+cu126、Python 3.10.20、Triton 3.8.0。没有把这些执行称为 Hopper/Blackwell 实验；之前的 H100/B200 TMA/TMEM 实机证据仍是另一组研究。所有本轮计时均为正确性执行相关墙钟，不测算子性能。

Triton 使用官方 3.8.0 wheel，加对应合并补丁中的准确 Python 源码修改；native compiler 完全相同。因此是可审计的补丁回移实验，不冒称完整历史父提交的 native 重编译。Liger 使用实际合并父提交与合并提交的完整 `src/`，经正常包导入执行，未重写成简化替身 kernel。来源、源码、原生编译器、测试器与输入身份均保存 SHA-256。

数值参考来自独立 CPU 数学合同：softmax 稳定公式、负零逐字节、constexpr 整数序列、PolyNorm float64 多项式归一化、sparsemax 单纯形投影、selective-log-softmax 的 float64 gather/mask。Liger 还核验 shape/dtype、输入内容/stride 和输入前后未变；独立审查用不同算法重算其三个参考。覆盖仅限冻结的前向合同，不涵盖全部梯度、完整模型训练、任意输入或整个项目的正确性。

## 6. 证据完整性、复现和投稿边界

独立验证保留全部设备输出及输入，不只保存通过标志或几个截图。11 项 Liger 防篡改测试覆盖丢失/重复 case、完整数组截断/修改、dtype、输入 mutation、同时篡改输入/参考/哈希及 stride。Triton 另有 8 项输出/身份测试，包括负零、删除整个根因、伪造 pass 和 JS/Python 路径排序差异。普通仓库测试 363 项通过；交互浏览器与真人流程软件检查另存。

最初 Triton 负零筛选误把 constexpr ±0.0 放在同一 kernel，触发额外 cache-key 混淆；最终按上游问题使用分立 literal 分支，初次记录仍保留而不冒充正式控制。Liger 的初次采集、补齐输入/dtype 约束后的控制、实际 `core.applyEdits` 官方补丁执行检查也分别归档，不把重复数扩大成缺陷数。候选生成前所有合同修订已结束。

生成期间另发现一个未追改的表示限制：JavaScript 冻结 JSON 时把数值 `-0` 写为 `0`，因此用该数值参数分组不能区分零的符号；两条件同样受影响。原始设备/参考字节仍明确保留符号位，实际 GPU 隐藏合同也保留正确的 literal ±0.0。页面绑定模型实际收到的同一冻结 catalog，负零从字节辨认。后续版本应以显式 sign bit/IEEE 编码传递，不能在本轮中途补提示或重跑有利结果。

已完成无模型、无 GPU 的完整归档解包复核：[清单](evidence/manifest.json)保存 10,243 个原文件的原始和存储哈希，原始大小 295,131,203 bytes，存储大小 236,165,729 bytes（不含清单自身）。[复核收据](roundtrip-verification.json)确认 36 次交互/补丁重放、全部候选完整输出及原始事实来源一致。[独立审计](audit/interruption-review.json)另核验两种中断恢复、候选身份、运行时映射和资源口径；它在归档后单独保存，不回改冻结证据。

在本机的一次离线复核测量中，墙钟 **7.45 s**，最大 RSS **145,648 kB**，退出码 0；见[原始计时](roundtrip-cost.log)。这仅覆盖解包后的重放与数值重算，排除解包、采集、模型和 GPU 执行；缓存和硬件条件相关，不是算子性能或完整调试成本。最终检查及文件哈希见[验证清单](validation.json)。可从仓库根目录执行：
